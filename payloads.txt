## Browser DevTools Network Tab

### Look for Exposed Secrets in:
- config.js (AWS keys, JWT secrets, admin passwords)
- api.js (API tokens, internal endpoints)
- auth.js (backup credentials, user enumeration)
- analytics.js (tracking IDs, API keys)

### Check Response Headers for:
- Missing security headers (CSP, X-Frame-Options)
- Exposed server information
- CORS misconfigurations

## Notes for Testing

1. All payloads should be tested through Burp Suite proxy
2. VISTA should detect most of these vulnerabilities automatically
3. Some payloads require interaction (clicking, hovering)
4. Check browser console for logged sensitive data
5. Monitor network tab for exposed secrets
6. Test with different browsers for compatibility

## Responsible Testing

⚠️ Only use these payloads on:
- Your own VulnBank deployment
- Systems you have permission to test
- Isolated testing environments

Never use on:
- Production systems
- Systems without authorization
- Real banking applications
- Other people's deployments
